# Primer.
A primer is a comprehensive introductory text designed to systematically present the foundational principles and core concepts of a specific subject. It serves as a baseline resource, establishing the essential knowledge, terminology, and framework required to understand a discipline. Consequently, its primary objective is to equip the reader with the necessary background for subsequent, more advanced study.

However, since I possess zero literary restraint and inevitably get lost in my own writing, these documents will frequently and violently overshoot *the basics*. Let's just blame it on my relentless, terminal need to deconstruct absolutely everything from **first principles**.

Keep in mind that I am a **self-professed amateur**, and not a single thing in this repository should be taken seriously.

Enjoy.
