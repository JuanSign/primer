{\small
\textbf{Counting occurrences.} Aho-Corasick: add 1 to the state after each text char, then add every count to \code|link| in reverse \code|q| order. SAM: \code|cnt = 1| on non-clone states, add to \code|link| by decreasing \code|len|. Eertree: add \code|cnt| to \code|link| from the last node down.
\par}

{\small
\textbf{Wildcard matching (FFT).} Letters $1..26$, wildcard $0$. Start $i$ matches iff $\sum_j p_j t_{i+j} (p_j - t_{i+j})^2 = 0$. Expand into three convolutions of the reversed $p^3, p^2, p$ with $t, t^2, t^3$ and read index $i + m - 1$. Use the double \code|conv|.
\par}
