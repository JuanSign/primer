\topic{Techniques}
{\small
\textbf{D\&C opt} needs $opt(i) \le opt(i + 1)$. \textbf{Knuth} needs $C$ monotone and $C(a, c) + C(b, d) \le C(a, d) + C(b, c)$ for $a \le b \le c \le d$.
\textbf{Convex hull trick.} $dp_i = \min_j (m_j x_i + b_j)$: \code|LineContainer| with negated lines.
\textbf{Aliens (WQS).} If the best value $f(k)$ with exactly $k$ items is convex, charge $\lambda$ per item, solve without the limit, binary search $\lambda$ until the chosen count is $k$, answer $g(\lambda) + \lambda k$. Break ties toward the larger count.
\textbf{Slope trick.} Keep a convex piecewise linear function as two heaps of breakpoints, add $|x - a|$ or prefix minima in $O(\log n)$.
\textbf{Bitset knapsack.} $b \mathrel{|}= b \ll w$ for each item, $O(nW/64)$.
\par}
